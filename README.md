# 含人量检测 · Human Made

一个用于短视频演示的手机端 H5 框架。

当前只包含最小闭环：

1. 粘贴一段文字；
2. 点击“开始检测”；
3. 查看含人量分数和句子高亮；
4. 点击“增加含人量”，回答两个追问；
5. 查看补充前后的分数变化，或重新检测下一段文字。

## 当前边界

- 当前分数、追问和提升结果由前端演示规则生成，不是正式 AI 分析结果。
- 不保存用户输入，不包含账号和数据库。
- 尚未接入模型接口，尚未公开发布。
- 后续可在保留界面的前提下，把本地演示规则替换成服务端 AI 接口。

## 本地运行

```bash
npm install
npm run dev
```
